# ai-study

LLM을 애플리케이션에 붙이고, 서빙하고, 운영하는 방법을 실습하며 익히는 기록이다. 모델 연구보다 응용 개발, 에이전트, 서빙과 파이프라인에 초점을 둔다. 실습마다 폴더 하나를 두고 목표, 절차, 측정 결과, 배운 점을 남긴다.

- 로컬 환경: NVIDIA GeForce RTX 4070 Laptop GPU (VRAM 8GB)
- 로컬에서 할 수 없는 실습은 GPU를 임대해 진행한다.
- 모델 호출 코드는 OpenAI 호환 API 형식으로 쓴다. 로컬 모델로 만든 코드를 주소와 키만 바꿔 클라우드 API에 붙일 수 있게 하기 위해서다.

## 실습 목록

체크는 해당 실습의 완료 조건을 확인한 뒤에 한다.

### 1단계. 로컬 (VRAM 8GB)

| # | 실습 | 축 | 완료 조건 | 완료 |
|---|---|---|---|---|
| 01 | [Ollama 로컬 챗, VRAM·속도 관찰](01-ollama-chat/) | 서빙 | Q4와 Q8의 VRAM, tokens/s를 표로 남김 | |
| 02 | 코드로 모델 API 호출과 구조화 출력(JSON) | 응용 | 텍스트 20건 이상을 스키마 검증을 통과하는 JSON으로 변환 | |
| 03 | RAG 파이프라인 (적재, chunking, 임베딩, 벡터 DB, 검색, 생성) | 응용 | 단계별 입출력을 확인하고, 질문 10개로 검색 적중과 답변을 평가 | |
| 04 | 도구 호출 (tool calling) | 에이전트 | 모델이 질문에 맞는 함수를 골라 호출하고, 결과로 답하는 흐름을 기록 | |
| 05 | 에이전트 루프와 하네스 (도구, 컨텍스트 관리, MCP 서버) | 에이전트 | 여러 단계 작업을 끝내는 에이전트와 과제 5개 평가 결과 | |
| 06 | 평가 하네스 (평가 세트, 자동 채점, 회귀 평가) | 응용 | 03과 05의 결과를 정답 비교와 LLM-as-judge로 자동 채점하고, 프롬프트 변경 전후 점수를 비교 | |

- 05는 로컬 모델로 도구 호출이 불안정하면 클라우드 API로 바꾼다.
