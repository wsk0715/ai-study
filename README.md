# ai-study

LLM을 직접 실습하며 익히는 기록이다. 실습마다 폴더 하나를 두고 목표, 절차, 측정 결과, 배운 점을 남긴다.

- 로컬 환경: NVIDIA GeForce RTX 4070 Laptop GPU (VRAM 8GB)
- 로컬에서 할 수 없는 실습은 GPU를 임대해 진행한다.

## 실습 목록

체크는 해당 실습의 완료 조건을 확인한 뒤에 한다.

### 1단계. 로컬 (VRAM 8GB)

| # | 실습 | 완료 조건 | 예상 시간 | 완료 |
|---|---|---|---|---|
| 01 | [Ollama 로컬 챗, VRAM·속도 관찰](01-ollama-chat/) | Q4와 Q8의 VRAM, tokens/s를 표로 남김 | 30분 | |
| 02 | 구조화 출력(JSON) 일괄 변환 | 텍스트 20건 이상을 스키마 검증을 통과하는 JSON으로 변환 | 1시간 | |
| 03 | 미니 RAG | 문서를 넣고 답했을 때와 넣지 않았을 때의 차이를 기록 | 2시간 | |
| 04 | QLoRA 맛보기 (3B~4B, 말투 학습) | 지시 없이도 학습한 말투가 나오는 출력 기록 | 반나절 | |

- 04는 Windows에서 학습 라이브러리 설치가 막히면 2단계로 옮긴다.

### 2단계. GPU 임대

| # | 실습 | GPU | 완료 조건 | 완료 |
|---|---|---|---|---|
| 05 | 같은 모델의 BF16과 Q4 품질·속도 비교 | 24GB | 같은 질문 10개의 답과 속도를 표로 비교 | |
| 06 | vLLM으로 OpenAI 호환 서버 띄우기 | 24GB | 로컬 PC에서 API 호출 성공 | |

- 임대 실습의 README에는 사용 시간과 비용을 적는다.
- 실습이 끝나면 인스턴스를 Terminate한다. Stop만 하면 스토리지 요금이 계속 나간다.
